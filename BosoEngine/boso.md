# Boso Script Language

Boso Script adalah bahasa pemrograman yang mirip C# namun menggunakan keyword bahasa Indonesia.

## Keyword Boso
| Boso | C# |
|------|-----|
| menggunakan | using |
| kelas | class |
| publik | public |
| privat | private |
| statis | static |
| jika | if |
| lain | else |
| untuk | for |
| selama | while |
| kembali | return |
| baru | new |
| string | string |
| angka | int |
| desimal | double |
| boolean | bool |
| benar | true |
| salah | false |
| tulis | Console.WriteLine |

## Contoh Dasar
```boso
menggunakan System;

kelas Program
{
    publik statis void Utama()
    {
        tulis("Halo dari Boso!");
    }
}
```

## Aturan Umum
1. Struktur kode sama seperti C#.
2. Keyword boleh diganti dengan keyword Boso.
3. Tipe data dan operasi menggunakan konsep C#.
