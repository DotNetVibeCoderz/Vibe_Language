# Samples

Four working pages, each showing a different part of CSJS. Build any of them with:

```bash
cs2js serve samples/01-hello-world
```

| | Shows |
| --- | --- |
| [01 — Hello World](01-hello-world) | A C# class transpiled to a module and called from HTML. |
| [02 — DOM Manipulation](02-dom-manipulation) | Building and updating DOM nodes from C#. |
| [03 — Event Handling](03-event-handling) | Clicks and keyboard, with C# events driving render. |
| [04 — Three.js](04-threejs) | `[JsImport]` bindings and a 3D scene written in C#. |

Read each sample's generated JavaScript beside its source — that is the fastest way to build an
intuition for what the transpiler does.
